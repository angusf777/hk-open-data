# Governance

## Current maintainer

HK Open Data begins as a founder-maintained project. The current maintainer is [@angusf777](https://github.com/angusf777).

## Decision process

Routine corrections and focused improvements are decided through issues and pull requests using published schemas, tests and project policies. Material changes to the hosted boundary, source-access defaults, licence, evidence semantics, security model or release process require a written design decision before implementation.

## Protected changes

The maintainer merges external contributions after required automated checks pass. Changes to workflows, deployment, source activation, provider egress, secrets, authentication, security controls and releases receive explicit maintainer review. No generated check may grant source approval or alter terms evidence automatically.

## Releases

Releases come from a clean, verified commit. Release notes distinguish repository verification from upstream authorization, live availability and production qualification. Published tags are not moved.

## Future maintainers

Additional maintainers may be invited after sustained, constructive contributions and demonstrated care with provenance, security, accessibility and community conduct. Appointments and removals are recorded publicly. The project does not create roles before people are ready to perform them.
