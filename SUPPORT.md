# Getting help

HK Open Data is maintained as an independent open-source project. There is no paid support desk,
service-level agreement, or guaranteed response time.

## Choose the right channel

- Use [GitHub Discussions](https://github.com/angusf777/hk-open-data/discussions) for setup
  questions, ideas, examples, and help choosing a source.
- Use a [bug report](https://github.com/angusf777/hk-open-data/issues/new?template=bug-report.yml)
  for a reproducible problem in this repository's code or catalogue interface.
- Use a [resource request](https://github.com/angusf777/hk-open-data/issues/new?template=resource-request.yml)
  to suggest a Hong Kong-relevant source.
- Use the [correction form](https://github.com/angusf777/hk-open-data/issues/new?template=correction.yml)
  for inaccurate metadata, attribution, source changes, or takedown concerns.
- Use [private vulnerability reporting](https://github.com/angusf777/hk-open-data/security/advisories/new)
  for security issues. Do not publish credentials, exploit details, or private data.

## Before asking

Search existing issues and discussions, identify the source or catalogue reference, include the
exact command and error where relevant, and remove credentials and provider response bodies.
Technical success in this project does not determine whether a proposed use is permitted; source
terms and applicable law remain controlling.
