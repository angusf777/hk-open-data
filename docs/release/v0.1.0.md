# HK Open Data v0.1.0

HK Open Data v0.1.0 publishes an independent bilingual catalogue and optional self-hosted data
access and API health tools.

## Included

- 521 metadata records: 265 official, 145 external, and 111 read-only MCP candidates.
- Static English and Traditional Chinese catalogue with search, filters, and deterministic links.
- Catalogue-only mode (`catalogue`) with no automatic requests to listed providers.
- API health-check mode (`observe`) with fingerprints and summary metadata only.
- Data-access mode (`fabric`) with complete-response storage only after the user enables it and
  records a source-specific review.
- REST and TypeScript/Python SDK surfaces plus 11 read-only MCP tools.
- Application-level request limiting with a documented `429` contract and explicit trusted-proxy
  boundary for the included admin and portal services.
- Synthetic connector fixtures, checksummed metadata package, and CycloneDX dependency SBOM.

## Safeguards

All seeded sources and connectors are inactive. The public Pages site is static and does not proxy,
mirror, cache, or call listed providers. Runtime containers are self-hosted, bounded, non-root,
read-only where practical, and use explicit egress boundaries.

Terms-review labels describe dated project research. They are not legal advice, provider
authorization, or a determination that commercial use, caching, redistribution, scraping, or other
processing is permitted. Original sources, current terms, technical controls, and applicable law
remain controlling.

## Known limitations

- Traditional Chinese summaries are marked `seeded` until human review is recorded.
- Link reachability and provider terms can change after the recorded check date.
- No hosted API, proxy, MCP endpoint, availability commitment, or production qualification is
  provided by the project.
- The optional runtime requires its user to configure identity, secrets, source reviews, retention,
  and infrastructure controls for the intended use.

## Checksums

The attached `SHA256SUMS` covers the catalogue JSON and CycloneDX SBOM. Verify with:

```sh
shasum -a 256 -c SHA256SUMS
```

Request metadata corrections or takedowns through the repository's structured issue form and
policy. Report vulnerabilities privately through GitHub Security Advisories as described in
`SECURITY.md`.
