# Tested quickstarts

These guides turn five useful Hong Kong public-data tasks into copyable commands backed by the
repository's current bounded verification evidence.

- [Public transport routes: New Lantao Bus](transport-routes.md) — Download the current New Lantao Bus route list as JSON.
- [Weather forecast: Hong Kong Observatory](weather-forecast.md) — Request the current Hong Kong local weather forecast as JSON.
- [Air quality: current AQHI by station](air-quality.md) — Download the current station-level Air Quality Health Index feed.
- [Geospatial data: traffic census cordons](traffic-geospatial.md) — Download Transport Department traffic-census cordon geometry in GML.
- [Company information: registered place of business](company-information.md) — Call the Companies Registry example for a registered non-Hong Kong company.

Verification is point-in-time technical evidence, not a provider endorsement, permission decision,
or guarantee. Check each guide's evidence date and the provider's current terms before use.
