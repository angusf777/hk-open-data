# Civic Signal brand usage

HK Open Data uses a project-authored Civic Signal identity: warm paper, disciplined ink, restrained
signal red, abstract data routes, and catalogue cards. It should feel independent, practical, and
public-interest oriented.

## Assets

- `assets/brand/hk-open-data-mark.svg` is the primary project mark and wordmark.
- `assets/brand/social-preview.png` is the 1280×640 repository social preview.
- `docs/images/` contains real application screenshots generated from committed catalogue data.

## Rules

- Keep the mark's proportions, clear space, colours, and readable contrast.
- Do not add a flag, bauhinia, government seal, agency/provider logo, or wording that suggests an
  official relationship.
- Do not use provider logos merely because their resources are listed.
- Do not combine the project mark with commercial-use, caching, redistribution, security, or legal
  permission claims.
- Screenshots must contain no credentials, private paths, provider payloads, or visitor analytics.

name, trademark, dataset, API, documentation, or other provider material.
