## GitHub release — English

HK Open Data v0.1.0 is an independent community catalogue and self-hosted toolkit for discovering
Hong Kong public data, APIs, and read-only MCP integrations. The release maps 521 resources—265
official, 145 external, and 111 MCP candidates—with visible provenance, verification dates, and
terms-evidence states. The hosted surface is a static, bilingual catalogue with no accounts,
analytics, provider requests, proxying, or copied datasets. Optional P01/P14 profiles run only in
infrastructure controlled by the user and keep sources inactive by default.

Evidence labels are not legal conclusions. Users must verify current upstream terms and applicable
law before commercial use, caching, redistribution, scraping, or other processing. Read the
[source-rights notice](../governance/SOURCE_RIGHTS.md).

## Developer and civic-tech communities — English

I built HK Open Data to make Hong Kong's public-data landscape easier to inspect and reuse
responsibly. It is a bilingual, source-backed catalogue with deterministic JSON, 521 resource
records, local SDK/API surfaces, and 11 read-only MCP tools. The static site never contacts listed
providers; optional observation and fabric profiles are self-hosted and fail closed. Corrections,
translations, accessibility improvements, and synthetic-fixture-backed connectors are welcome.
